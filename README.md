# [서비스 이름]

실시간 이슈 기반 인사이트 공유 플랫폼

## 서비스 소개

[서비스 이름]은 추천 알고리즘으로 인한 필터 버블과 편향된 정보 소비를 완화하기 위한 실시간 이슈 기반 토의 플랫폼이다.

사용자는 하나의 이슈에 대해 다양한 관점의 주장, 근거, 토론 흐름을 함께 확인할 수 있다. 단순히 의견을 소비하는 것이 아니라 서로 다른 관점을 비교하고 토론하며 균형 잡힌 정보를 탐색하는 것을 목표로 한다.

## 문제 정의

최근 유튜브, SNS, 커뮤니티 플랫폼은 사용자의 관심사와 선호도를 기반으로 콘텐츠를 추천한다. 이 방식은 원하는 정보를 빠르게 제공한다는 장점이 있지만, 비슷한 의견과 정보만 반복적으로 접하게 되는 필터 버블을 만들 수 있다.

필터 버블 환경에서는 다양한 관점과 근거를 접하기 어렵고, 특정 의견에 대한 확신만 강화될 수 있다. 또한 기존 커뮤니티에서는 서로 다른 의견이 감정적인 대립으로 이어지는 경우가 많아 하나의 이슈를 객관적으로 이해하기 어렵다.

[서비스 이름]은 최신 이슈를 중심으로 토론방을 만들고, 자유 채팅, 발언권 기반 메인 스테이지, 의견 작성, 근거 업로드, 토론 종료 리포트를 통해 하나의 이슈를 다양한 관점에서 이해할 수 있도록 돕는다.

## 핵심 가치

- 최신 이슈를 빠르게 토론 주제로 전환
- 하나의 쟁점에 대한 다양한 관점 제공
- 감정적 대립보다 근거 중심의 토의 환경 제공
- 자유 채팅과 메인 스테이지 발언을 분리한 토론 경험 제공
- 토론 종료 후 핵심 흐름과 하이라이트를 리포트로 요약
- 주니어 백엔드 개발자가 학습 가능한 복합 도메인 제공

## 타겟 사용자

- SNS로 사회 이슈를 접하는 20-40대 이용자
- 편향된 정보 소비에 피로감을 느끼는 이용자
- 하나의 이슈를 다양한 관점으로 이해하고 의견을 나누고 싶은 이용자
- 특정 이슈를 활용하려는 크리에이터 또는 마케터
- 특정 이슈와 연관된 기업 또는 브랜드 담당자

## 핵심 기능

### 1. 최신 트렌드/토픽 기반 주제 생성

외부 API를 사용해 최신 이슈와 토픽을 수집하고, 관리자가 승인한 토픽을 토론방으로 오픈한다.

### 2. 무제한 자유 대화 룸

인원 제한 없는 공개 토론 공간에서 다수의 사용자가 실시간으로 대화한다. Read-heavy 구조를 고려해 채팅 이력 조회와 메시지 저장 전략을 설계한다.

### 3. 메인 스테이지 발화 예약 및 타임아웃 관제

사용자는 발언권을 신청하고, 발언권을 얻은 사용자는 정해진 시간 동안 메인 스테이지에서 의견을 제시한다. 시간이 종료되면 다음 순번으로 자동 전환된다.

### 4. 가상 재화 충전 결제

Toss Payments 등 외부 PG API를 연동해 가상 재화 충전 결제를 처리한다. 결제 승인, 실패, 중복 요청, 결제 이력 조회를 백엔드에서 안전하게 관리한다.

### 5. 토론 종료 후 하이라이트 리포트 생성

토론방 종료 후 채팅 로그, 의견, 근거 자료, 주요 발언, 공감 흐름을 분석하여 하이라이트 리포트를 생성한다.

### 6. 악성 유저 차단 및 Rate Limiter

도배, 매크로, 과도한 API 요청을 방지하기 위해 사용자별 요청 속도를 제한하고 시스템 안정성을 보호한다.

## 핵심 사용자 흐름

```text
최신 토픽 생성
   ↓
관리자 승인
   ↓
토론방 오픈
   ↓
유저 입장
   ↓
자유 채팅
   ↓
발화권 신청
   ↓
메인 스테이지 발언
   ↓
실시간 공감 / 반응
   ↓
토론 종료
   ↓
하이라이트 리포트 생성
```

## 1차 MVP 범위

1차 MVP는 `P0` 요구사항을 우선 구현한다.

1. 회원가입
2. 로그인
3. 실시간 이슈 생성
4. 토픽 승인
5. 토론방 생성
6. 토론방 입장
7. 토론방 자동 종료
8. 자유 채팅
9. 채팅 이력 조회
10. 메인 의견 작성
11. 근거 링크 첨부
12. 이미지 첨부
13. 발언권 신청
14. 발언권 자동 부여
15. 발언권 만료
16. 가상 재화 충전 결제 요청
17. 가상 재화 충전 결제 승인

## 기술 스택

- Backend: Spring Boot, Spring Data JPA
- Database: MySQL
- Cache / Realtime Support: Redis
- Authentication: JWT
- Payment: Toss Payments API
- AI 활용: Gemini PR 리뷰, Codex 하네스 엔지니어링
- Collaboration: Jira, GitHub Pull Request
- Infra: AWS
